# 3.1 Historical Source-Control Ownership Audit

Mục **3.1** trong [uc.md](../../../requirements/uc.md) là thống kê lịch sử Git/ownership,
không có dòng UC nghiệp vụ. Vì vậy thư mục này **không tạo sequence diagram giả** cho
một thao tác đăng nhập, đăng bài hoặc giao đồ.

Các sơ đồ của Đạt bắt đầu từ mục **3.2**, rồi **3.3** và **3.4**, tổng cộng **34 UC**.
Không đổi số catalogue hoặc tái gán lịch sử implementation để lấp mục 3.1.
